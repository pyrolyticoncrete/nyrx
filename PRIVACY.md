# Privacy Policy

**nyrx** is a terminal media aggregator that runs entirely on your local
machine. This policy explains what the app does and does not do with your data.

## What nyrx Does Not Do

- nyrx does not require you to create an account or log in to any service.
- nyrx does not connect to your Youtube, Soundcloud, or any other
  third-party account.
- nyrx does not collect, transmit, or share any personal data, usage analytics,
  or telemetry.
- nyrx does not have a first-party backend server. There is no remote database,
  no analytics endpoint, no crash reporting service operated by nyrx.
- nyrx does not send your search queries, playback history, or other activity to
  any server operated by nyrx. TV/Movies metadata is fetched through a
  third-party TMDb proxy (see "TMDb Metadata" below), so those queries go to
  that proxy rather than to nyrx.

## What nyrx Does Locally

All data generated by nyrx stays on your machine. This includes:

- **Search history** per source, stored in your local config directory.
- **Watch history**, stored in a local SQLite database (`watch_history.db`) and
  a JSONL tracker file (`tracker_v4.jsonl`).
- **Liked tracks and follows** (SoundCloud mode), stored in a local SQLite
  database (`sc_data.db`).
- **Bookmarks and watchlist** (TV/Movies mode), stored locally.
- **App settings and configuration**, stored in `config.json` within your
  config directory.
- **Downloaded media files**, saved to your chosen download directory.

All of these files are stored in standard platform directories (via
`platformdirs`) and are accessible only to you on your local system.

## Network Activity

nyrx makes network requests only when you explicitly trigger them:

- **Searching** sends queries to YouTube, Soundcloud, or (for TV/Movies) a
  third-party TMDb proxy. These are standard requests made on your behalf.
- **Playing** streams media via mpv from URLs returned by the source. The stream
  comes directly from the third-party host, not through nyrx.
- **Downloading** saves media files from third-party sources directly to your
  machine.
- **TV/Movies server probing** uses Lua scripts with headless Chromium (via
  Playwright) or HTML to find working streaming URLs on public websites.
- **Hotswap** (optional) fetches TV/Movies server configurations from a remote
  manifest URL that you configure. No manifest URL is set by default. This can
  be enabled, disabled, or changed at any time via the command palette.

None of these requests include personal identifiers. nyrx does not set tracking
cookies, does not include user-agent strings that identify you, and does not log
or store request/response data beyond what is needed for the current operation.
Sandbox logs (if enabled via --debug) are written to a local log file and are
not transmitted anywhere.

## TMDb API Keys

TV/Movies search, details, and browsing are fetched through a third-party
TMDb proxy that nyrx discovers at runtime, nyrx does not operate this proxy,
and your metadata queries are sent to it rather than to nyrx. No TMDb API key 
is currently required to use TV/Movies mode. For extra reliability or to avoid the 
third-party proxy, you can supply your own free TMDb API key via the command 
palette ("Connect TMDb API key"), or point nyrx at your own proxy by
setting `tmdb_proxy` in `keys.json`. A maintained, open-source nyrx-operated
proxy could be added in a future release.

## Local Files

All configuration, cache, and data files are stored in platform-standard
directories:

- Config: `~/.config/nyrx/` (Linux)
  `~/Library/Application Support/nyrx/` (macOS)
- Cache: `~/.cache/nyrx/` (Linux), `~/Library/Caches/nyrx/` (macOS)

You can delete these directories at any time to remove all nyrx data from your
system.

## Third-Party Services

nyrx interacts with third-party services (YouTube, SoundCloud, TMDb,
radio-browser.info) as a scraping client. TV/Movies server configs, which are
user-configured, may connect to additional third-party websites to find
streaming URLs. Your interaction with these services through nyrx is subject to
their own terms of service and privacy policies. nyrx does not mediate, store,
or modify your relationship with these services beyond the local data it
maintains for app functionality.

## Secrets

If you use TV/Movies server configs that require API keys or tokens, these are
stored locally in `secrets.json` in your config directory. Each server config
can only access its own keys. They are scoped by server name and cannot be read
by other configs or the app itself.

## Changes to This Policy

If this privacy policy changes, the updated version will be available in the
nyrx repository. Continued use of the app after changes constitutes acceptance
of the updated policy.
